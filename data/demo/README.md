# Demo Datasets (Chamoli Testbed)

This folder contains pre-configured spatial demo geometries and benchmark records for the Chamoli Glacial Outburst scenario:
- **Sentinel-1 SAR Scene Metadata**: Orbit descending/ascending, Dual-pol (VV+VH), 10m spatial resolution.
- **Sentinel-2 MSI Scene Metadata**: Bands B2, B3, B4, B8, B11.
- **Copernicus 30m DEM**: Hydrographic elevation profiles along Dhauliganga gorge.
- **OpenStreetMap Baseline**: Pre-disaster road networks, bridges, settlements, and civil structures.
